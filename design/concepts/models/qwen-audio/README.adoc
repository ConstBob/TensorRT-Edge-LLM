= Qwen Audio and TTS Architecture
{nbsp}
:description: Architecture notes and implementation pointers for Qwen audio and text-to-speech models in TensorRT Edge-LLM

== Overview

Qwen audio models reuse Qwen3 decoder-style blocks but add audio-specific
front-end or back-end components. ASR uses an audio encoder/projector before the
LLM decoder. TTS uses thinker/talker/code-predictor exports and speech-code to
waveform runtime components.

== Edge-LLM Integration Notes

* ASR direction is audio-to-text: audio features are projected into the decoder
  input stream before normal token generation.
* TTS direction is text-to-speech-code: the talker and code predictor are
  exported as Qwen3-like decoder components, with waveform synthesis handled by
  the downstream Code2Wav path.
* Qwen3-TTS has no audio encoder in the Edge-LLM path; avoid grouping its
  internals with ASR audio-encoder logic.
* Template and placeholder behavior is audio-specific and should be reviewed
  with tokenizer/chat-template export changes.
