= Nemotron-H Hybrid Architecture
{nbsp}
:description: Architecture notes and implementation pointers for Nemotron-H checkpoints in TensorRT Edge-LLM

== Overview

Nemotron-H checkpoints use a hybrid decoder that interleaves attention with
state-space/Mamba-style sequence mixing. Edge-LLM documents this architecture
separately because export/runtime must carry recurrent state bindings in
addition to the usual KV-cache path.

== Edge-LLM Integration Notes

* Hybrid layers add state-space recurrent state inputs/outputs beside the
  standard attention KV cache. Binding-mode explanations belong in the
  state-space and attention/KV-cache component docs.
* INT4 support is constrained by group-size and checkpoint weight dimensions;
  the user-facing support matrix records the precision status.
* Nemotron template handling is explicit for the 9B Nano v2 checkpoint and
  should remain an export option rather than hidden family logic.
* Any routed-expert or state-space variant should link to the reusable
  link:../../components/moe/[MoE] and link:../../components/state_space/[state-space]
  component contracts.
