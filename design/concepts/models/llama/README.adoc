= Llama Decoder Architecture
{nbsp}
:description: Architecture notes and implementation pointers for Llama decoder checkpoints in TensorRT Edge-LLM

== Overview

Llama checkpoints use the standard dense decoder-only transformer path: token
embeddings, RoPE, RMSNorm, grouped-query self-attention, dense gated MLP, KV
cache, and LM head. Edge-LLM handles this architecture through the default
`CausalLM` implementation rather than a Llama-specific model class.

== Support Source of Truth

The supported checkpoint list, precision matrix, and HF profile links live in

Do not duplicate that table here.

== Edge-LLM Integration Notes

* This is the baseline dense decoder path used to validate shared tokenizer,
  RoPE, attention, KV-cache, FFN, residual, and LM-head contracts.
* Llama-family differences are mostly config-driven: head count, KV head count,
  RoPE parameters, hidden sizes, and chat-template metadata.
* Keep implementation detail in reusable component docs unless Llama needs a
  unique Edge-LLM contract.
