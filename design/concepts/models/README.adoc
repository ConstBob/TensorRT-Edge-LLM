= Model Architecture Design Index
{nbsp}
:description: Architecture-level model notes for TensorRT Edge-LLM

== Purpose

`design/concepts/models/` is an architecture index. Pages are keyed to the model
architecture reported by checkpoint `config.json` (usually `model_type` or the
Transformers architecture class), not to every supported marketing family.

The complete user-facing checkpoint support matrix is
link:../../../docs/source/user_guide/getting_started/supported-models.md[Supported Models].
Do not duplicate checkpoint lists, precision matrices, or HF profile tables in
this tree.
