= InternVL Architecture
{nbsp}
:description: Architecture notes and implementation pointers for InternVL checkpoints in TensorRT Edge-LLM

== Overview

InternVL integrates an InternViT visual encoder/projector with a language
backbone that still reuses the common decoder contracts. The main Edge-LLM
specific concerns are visual preprocessing, pixel-shuffle/projector behavior,
and the handoff from image sentinels to decoder embeddings.

== Edge-LLM Integration Notes

These notes call out what is different from a plain decoder-only LLM in
Edge-LLM:

* The custom path is the InternVL visual encoder/projector export. The text
  decoder still uses the shared attention, KV-cache, FFN, and LM-head
  contracts after visual embeddings are inserted.
* Runtime replaces image sentinel tokens with embeddings produced by the
  InternVL visual runner before normal decoder prefill/decode.
* InternVL3.5 files are present in this branch, but they are implementation
  pointers only until a checkpoint appears in the Supported Models matrix.
