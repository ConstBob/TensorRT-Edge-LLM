= Qwen Vision-Language Architecture
{nbsp}
:description: Architecture notes and implementation pointers for Qwen-family vision-language models in TensorRT Edge-LLM

== Overview

Qwen VLM checkpoints combine a Qwen text decoder with a visual encoder and a
multimodal embedding handoff. The visual path produces image/video embeddings
and optional deepstack features before the decoder consumes a fused text/visual
embedding stream.

== Edge-LLM Integration Notes

* Qwen2-VL and Qwen2.5-VL share the Qwen2.5 visual export wrapper in this
  branch; config values select the exact checkpoint behavior.
* Qwen3-VL adds deepstack visual features. Treat deepstack as an embedding
  contract rather than a separate checkpoint-support list.
* Qwen3.5 checkpoints are unified text+VLM checkpoints: the same checkpoint can
  use the text-only `qwen3_5` handler or the Qwen3-family visual path when
  visual inputs are present. Its visual encoder reuses the Qwen3-VL
  architecture with deepstack disabled, while its text decoder remains the
  Qwen3.5 hybrid GDN/gated-attention decoder.
* Cosmos Reason2 is a Qwen3-family VLM packaging case. Keep the support entry
  in Supported Models and use this page for modality-specific implementation
  notes.
* The C++ runtime consumes visual features through the multimodal runner before
  normal decoder prefill/decode.
