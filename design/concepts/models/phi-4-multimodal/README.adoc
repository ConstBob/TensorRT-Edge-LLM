= Phi-4 Multimodal Architecture
{nbsp}
:description: Architecture notes and implementation pointers for Phi-4 multimodal checkpoints in TensorRT Edge-LLM

== Overview

Phi-4 multimodal combines a Phi-family text decoder with a dedicated vision
encoder/projector and template handling. Edge-LLM documents this separately
because the visual path, long-RoPE text setup, and chat-template requirements
are distinct from Qwen VLMs.

== Support Source of Truth

link:../../../../docs/source/user_guide/getting_started/supported-models.md[Supported Models].

== Edge-LLM Integration Notes

* The C++ runtime renders the checkpoint's provider Jinja directly, including
  its multimodal placeholders.
* Visual features enter through the multimodal embedding path; decoder-side
  attention, KV cache, FFN, and residual contracts remain shared.
* Keep long-RoPE and multimodal-position behavior linked to the positional
  encoding and embeddings component docs rather than duplicating upstream code.
