= Residual Connections
{nbsp}
:description: Residual connections in TensorRT Edge-LLM: standard residual paths and extension points

== Overview

Residual connections add a sublayer input to its output, allowing hidden
states to flow directly through the network. Every standard decoder block
has two residual additions:

1. **Post-attention residual**: adds block input to attention output.
2. **Post-FFN residual**: adds the post-attention result to FFN output.

== Model Applicability

[cols="2,2,3"]
|===
| Model Family | Residual Type | Notes

| Llama, Qwen, Phi, InternVL
| Standard
| Simple element-wise add at both residual points.

| Qwen3.5 hybrid
| Standard residual adds around heterogeneous mixers
| Residual shape/dtype behavior is still standard, while the mixer may be full
  attention or GDN linear attention.
|===

== Architecture

[mermaid]
----
graph TD
    H_IN[Block Input] --> NORM1[Pre-Attn Norm]
    NORM1 --> ATTN[Attention]
    H_IN -->|skip| RES1((+))
    ATTN --> RES1
    RES1 --> NORM2[Pre-FFN Norm]
    NORM2 --> FFN[FFN]
    RES1 -->|skip| RES2((+))
    FFN --> RES2
    RES2 --> H_OUT[Block Output]
----

== Variant Documents

No reusable residual variant documents are currently part of the
mainline design tree. New residual-routing mechanisms should be added
here only when their design is broadly reusable and not a private
adaptation for a single model family.

== Design

Residual adds preserve hidden shape and dtype expectations across sublayers.
They connect the unmodified sublayer input to attention, FFN, MoE, or
state-space outputs before the next normalization step.
