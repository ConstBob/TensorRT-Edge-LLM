= Component Design Index
{nbsp}
:description: Index of reusable TensorRT Edge-LLM component design documents

== Purpose

`design/concepts/components/` contains reusable component design docs. Each component page
explains why the component is needed and how it is implemented in Edge-LLM.
Model-specific wiring lives under `design/concepts/models/` and links back here instead of
duplicating component details.

`design/llm/` remains top-level because loader/model-construction notes are not a
single reusable transformer component.
